# UE5 GAS: Aura Master of the Elements

⚠️This is still a Work-In-Progress. Very early in development! About 25% done. ⚠️

---
This is an Online Multiplayer Top-Down RPG. 

I am currently making this by following a udemy course about Unreal Engine 5's Gameplay Ability System (GAS).

There's not much gameplay yet, just a scene with some random stuff, I'm still mainly setting up the code to build on it later. 

Currently implemented features:
- Character movement
- Ability system components
- Attribute sets replicated for online play
- Basic Health and Mana UI
- Gameplay effects
- Attributes system with primary secondary attributes
- Attributes menu
- Abilities structure
